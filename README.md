# RSNA Knee Abnormality Detection

This project is developed for the Kaggle competition: [RSNA Knee Abnormality Detection](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection).

The goal is to build an AI model that analyzes knee MRI studies and predicts 12 types of abnormalities from imaging data and associated radiology reports.

## Project Overview

Knee MRI scans contain rich diagnostic information but are time-consuming to interpret manually. This project develops a deep learning pipeline to process MRI series metadata and predict multiple abnormalities per study.

This is a **multi-label classification** problem — each study may contain more than one abnormality, and the model outputs a probability (0-1) for each of 12 target labels.

## Target Labels

| Label | Description |
|---|---|
| `ACL` | Anterior Cruciate Ligament tear |
| `MCL` | Medial Collateral Ligament injury |
| `Medial Meniscus` | Medial meniscus tear |
| `Lateral Meniscus` | Lateral meniscus tear |
| `Medial OA` | Medial compartment osteoarthritis |
| `Lateral OA` | Lateral compartment osteoarthritis |
| `PF OA` | Patellofemoral osteoarthritis |
| `Effusion` | Joint effusion |
| `Synovitis` | Synovial inflammation |
| `Baker's` | Baker's cyst |
| `Contusion` | Bone contusion |
| `Fracture` | Bone fracture |

### train.csv

Study-level labels for the training set (58,555 studies).

| Column | Description |
|---|---|
| `StudyInstanceUID` | Unique DICOM study identifier |
| `Report` | Full radiology report text (multilingual: English, Spanish, Dutch, etc.) |
| `ACL` ... `Fracture` | Binary labels (0 = absent, 1 = present) for each of the 12 target conditions |

> Note: Label columns may be partially empty — not all studies have complete annotations for every condition.

### train_series.csv / test_series.csv

MRI series-level metadata (one row per series within a study).

| Column | Description |
|---|---|
| `StudyInstanceUID` | Links to the parent study |
| `SeriesInstanceUID` | Unique DICOM series identifier |
| `Fluid_Sensitive` | Whether the sequence is fluid-sensitive (1 = yes, 0 = no) |
| `Fat_Suppression` | Whether fat suppression was applied (1 = yes, 0 = no) |
| `Anatomical_Plane` | Acquisition plane: Sagittal, Coronal, or Axial |

### test.csv

Contains only `StudyInstanceUID` for each test study.

### sample_submission.csv

Shows the required submission format: one row per `StudyInstanceUID` with probability columns for all 12 labels (values between 0 and 1).

## Code Structure

### `src/eda.py`
Runs exploratory data analysis on the CSV files. Saves 5 plots to `plots/` and a text report to `results/eda_results.txt`.
```bash
python src/eda.py
```

### `scratch/pseudo_label_generator.py`
Parses all 58,555 radiology reports using a multilingual keyword lexicon (English, Spanish, Dutch, Turkish, Greek) with negation detection. Writes `data/train_pseudo_labeled.csv` with labels filled in for every study.
```bash
python scratch/pseudo_label_generator.py
```

### `src/dataset.py`
PyTorch `Dataset` that loads DICOM slices from the `train_series/` folder, sorts them anatomically by Z-position, resizes each slice to `(H, W)`, and resamples the series to a fixed number of slices. Returns a `(1, D, H, W)` volume tensor.

### `src/model.py`
EfficientNet-B0 backbone (from `timm`) with 2D slice aggregation:
- Reshapes the 3D volume into individual 2D slices
- Encodes each slice through the CNN backbone
- Mean-pools slice features
- Outputs 12 raw logits via a linear classification head

### `src/train.py`
Full training pipeline:
- Loads `data/train_pseudo_labeled.csv`
- Splits into 80/20 train/val at the study level
- Trains with `BCEWithLogitsLoss`
- Saves the best checkpoint to `model_best.pt`

> **Run on Kaggle Notebooks** — update `DATA_DIR` in `CONFIG` to `/kaggle/input/rsna-knee-abnormality-detection` before running.

### `src/predict.py`
Loads a saved checkpoint, runs inference on test studies, and writes `submission.csv` in the exact Kaggle format.

## Data Analysis & Key Findings

Before choosing models, we analyzed the actual training data:

| Fact | Value | Implication |
|---|---|---|
| Total train studies | 4,407 | Full training set |
| Studies with image labels | **58** (1.3%) | Far too few to train vision model from scratch |
| Studies with radiology reports | **4,407** (100%) | Reports are the primary signal |
| Report languages | English, Spanish, Dutch | Must use a multilingual NLP model |
| MRI series per study | 5.5 avg (3–14 range) | Multi-view inputs for vision models |
| Test studies | 3 | Tiny test set — generalization matters |

**Label distribution (out of 58 labeled studies):**

| Label | Positives | Label | Positives |
|---|---|---|---|
| Effusion | 35 | Medial OA | 15 |
| Synovitis | 27 | Baker's | 12 |
| Medial Meniscus | 26 | Lateral OA | 11 |
| ACL | 24 | MCL | 9 |
| Lateral Meniscus | 23 | Contusion | 19 |
| PF OA | 21 | Fracture | 18 |

> Heavy class imbalance across all 12 labels. Focal loss or weighted BCE is required.

**Critical insight:** The ground truth labels are derived from radiology reports. An NLP model trained on all 4,407 reports will significantly outperform a vision model trained on only 58 labeled studies.

## Model Selection

### Why NLP First

Since only 58 studies have image-level labels but all 4,407 have radiology reports, the NLP model has 75x more training signal than any vision-only approach. The labels are directly inferable from the report text.

### Chosen Models

#### Stage 1 — NLP Model (run locally, no images needed)

| Model | Decision | Reason |
|---|---|---|
| **XLM-RoBERTa-base** | **Selected** | Multilingual (English/Spanish/Dutch), 4,407 training samples, strong on clinical text |
| XLM-RoBERTa-large | Backup | Better accuracy, higher GPU RAM requirement |
| mBERT | Alternative | Lighter but weaker than XLM-RoBERTa |
| BiomedBERT | Rejected | English-only — misses Spanish and Dutch reports |

#### Stage 2 — Vision Model (run on Kaggle with full DICOM data)

| Model | Decision | Reason |
|---|---|---|
| **EfficientNet-B0** | **Implemented (baseline)** | Fast baseline — 2D slice aggregation, already in `src/model.py` |
| **EfficientNet-B4** | **Planned** | Proven Kaggle medical imaging winner, stronger than B0 |
| **ConvNeXt-Base** | **Planned** | Modern CNN, often beats EfficientNet on small labeled sets |
| MaxViT-Tiny | Optional | Hybrid CNN+attention, strong on 2D MRI slices |
| Video Swin Transformer | Optional | Treats MRI slices as video frames — good for 3D volumes |
| 3D ResNet | Rejected | 58 labeled studies → severe overfitting without pseudo-labels |

#### Stage 3 — Ensemble

Weighted average of NLP + Vision predictions. Typically adds +1–3% AUC in Kaggle medical competitions.

### Training Pipeline

```
Stage 1 (local)    XLM-RoBERTa-base
                   ├── Input:  4,407 multilingual radiology reports
                   ├── Output: probabilities for 12 labels
                   └── Result: first submission + pseudo-labels for all studies

Stage 2 (Kaggle)   EfficientNet-B4  +  ConvNeXt-Base
                   ├── Input:  MRI DICOM images (569 GB, all planes)
                   ├── Labels: pseudo-labels from Stage 1 + 58 ground truth
                   └── Result: vision predictions per study

Stage 3 (final)    Ensemble
                   ├── 50% NLP predictions + 50% Vision predictions
                   └── Per-label threshold tuning for final submission
```

## Missing Data Analysis & Strategy

### What is Missing

| Data | Missing | Status |
|---|---|---|
| Image labels | **4,349 studies (98.7%)** | By design — handled via pseudo-labeling |
| Radiology reports | 0 | 100% complete |
| Series metadata | 0 | 100% complete |

There is only **one missing data problem** — the image labels. Reports and series metadata are completely clean with no imputation needed.

### Why 98.7% of Labels Are Missing

This is not a data quality issue. The competition is intentionally designed this way. Organizers manually labeled only 58 studies and expect participants to extract the remaining labels from radiology reports. The reports contain the diagnosis text (e.g. *"rotura de menisco interno"* = medial meniscus tear) — the ground truth is already inside them.

### Problem 1 — 4,349 studies have no image labels

**Fix: Pseudo-labeling via NLP**

```
58 labeled studies
       ↓
Fine-tune XLM-RoBERTa on (report → labels)
       ↓
Run on all 4,349 unlabeled reports
       ↓
Generate pseudo-labels (probabilities for all 12 conditions)
       ↓
Use pseudo-labels to train vision model on full 569 GB DICOM data
```

The 4,349 unlabeled studies are not truly unlabeled — their labels are recoverable directly from the report text.

### Problem 2 — Only 58 labeled studies to train on

**Fix: Fine-tuning, not training from scratch**

XLM-RoBERTa is pre-trained on billions of multilingual words and already understands medical language. Fine-tuning on 58 examples is sufficient — you are teaching it your label format, not teaching it language from zero.

### Problem 3 — Class imbalance within the 58 labeled studies

| Label | Positives | Label | Positives |
|---|---|---|---|
| Effusion | 35 / 58 | Medial OA | 15 / 58 |
| Synovitis | 27 / 58 | Baker's | 12 / 58 |
| Medial Meniscus | 26 / 58 | Lateral OA | 11 / 58 |
| ACL | 24 / 58 | MCL | **9 / 58** |

MCL has only 9 positives — the most imbalanced label.

**Fix:**
- **Focal Loss** instead of standard Binary Cross Entropy — down-weights easy negatives, focuses training on hard positives
- **Per-label threshold tuning** at inference time — don't use 0.5 uniformly across all labels
- **Stratified K-Fold** cross-validation — ensures each fold has enough positive examples per label

### Summary

| Problem | Root Cause | Solution |
|---|---|---|
| 98.7% image labels missing | Competition design | Pseudo-label via XLM-RoBERTa on reports |
| Only 58 labeled studies | Same | Fine-tune pre-trained multilingual model |
| Class imbalance | Rare conditions (MCL = 9 positives) | Focal loss + per-label threshold tuning |
| Missing reports | None — 0 missing | No action needed |
| Missing series metadata | None — 0 missing | No action needed |

## Modeling Approach

- **MRI slice selection** from relevant anatomical planes (Sagittal for ACL/meniscus, Coronal for OA, Axial for patellofemoral)
- **DICOM preprocessing**: windowing, normalization, resizing
- **Series metadata features**: fluid sensitivity, fat suppression, plane type
- **Radiology report NLP**: XLM-RoBERTa-base for multilingual report classification
- **CNN backbone**: EfficientNet-B4 and ConvNeXt-Base trained on pseudo-labeled DICOM images
- **Multi-label binary classification** with focal loss (class imbalance)
- **Threshold tuning** per label for final probabilities
- **Ensembling** NLP + Vision predictions

- Probability calibration before submission
